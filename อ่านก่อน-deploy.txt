SWI Foods — Smart QA (PWA) — ไฟล์สำหรับ deploy ขึ้น Cloudflare Pages
====================================================================
อัปโหลดไฟล์ทั้งหมดนี้ขึ้น GitHub แล้วต่อ Cloudflare Pages

⚠️ สำคัญ: ตอนสร้าง Cloudflare project ต้องเลือกแท็บ "Pages" → Connect to Git
   (ไม่ใช่ Create Worker) และตั้งค่า:
   - Framework preset: None
   - Build command: (เว้นว่าง)
   - Build output directory: /
   ห้ามให้มี "npx wrangler deploy" ใน build command เด็ดขาด (เป็นของ Worker)

ขั้นตอน:
1) GitHub → New repository ชื่อ swi-qa-app
2) Add file → Upload files → เลือกไฟล์ทั้งหมดนี้ → Commit
3) Cloudflare → Workers & Pages → Create → แท็บ Pages → Connect to Git
4) เลือก repo → Framework preset: None, build command ว่าง, output dir: /
5) Save and Deploy → ได้ URL https://swi-qa-app.pages.dev
